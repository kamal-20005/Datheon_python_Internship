# Machine Learning Projects – Classification, Regression & Churn Prediction

## Project Overview

This repository contains three Machine Learning projects developed using Python. These projects demonstrate practical implementation of supervised learning techniques, data preprocessing, feature engineering, model training, and performance evaluation.

The three projects cover classification, regression, and ensemble learning approaches using different real-world datasets.
## Projects Included

### 1. Iris / Wine Classification

**Objective:**

To implement supervised machine learning classification models using the Iris or Wine dataset and compare their performance.

**Key Tasks:**
- Load and explore the dataset.
- Perform data preprocessing.
- Apply feature scaling using StandardScaler.
- Split the dataset into 80% training and 20% testing.
- Train Logistic Regression and Decision Tree models.
- Compare model performance.

**Models Used:**
- Logistic Regression
- Decision Tree Classifier

**Evaluation Metrics:**
- Accuracy
- Precision
- Recall
- F1-Score

### 2. California Housing Price Prediction

**Objective:**

To predict median house values using the California Housing dataset through different regression techniques.

**Key Tasks:**
- Load and explore the dataset.
- Handle missing values using imputation.
- Perform feature engineering and create interaction features.
- Identify and handle multicollinearity.
- Train and compare multiple regression models.

**Models Used:**
- Ordinary Least Squares (OLS)
- Ridge Regression (L2)
- Lasso Regression (L1)

**Evaluation Metrics:**
- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)
- R² Score

### 3. Telecom Customer Churn Prediction

**Objective:**

To predict whether telecom customers are likely to leave a service using machine learning classification and ensemble techniques.

**Key Tasks:**
- Load and explore telecom customer subscription data.
- Perform data cleaning and preprocessing.
- Encode categorical features using OneHotEncoder.
- Handle class imbalance using SMOTE or class weighting.
- Train and compare ensemble classification models.
- Evaluate model performance using ROC-AUC.

**Models Used:**
- Random Forest Classifier
- XGBoost Classifier

**Evaluation Metrics:**
- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC Score

**Target:**
Achieve ROC-AUC score greater than 80%.
